# 3124004059 第一次个人编程作业 - 论文查重

## 项目简介
本项目为软件工程第一次个人编程作业，实现了一个基于 Java 的论文查重算法。程序通过命令行参数读取原文和抄袭版论文，计算出重复率并输出到指定答案文件中。

## 运行环境
- JDK 21
- Maven 3.8+
- IntelliJ IDEA 2024.2.4

## 算法说明
1. **HTML标签剥离**：自动剥离测试文件中可能混入的 HTML 网页代码。
2. **文本预处理**：只保留中文、英文、数字，英文转小写，忽略标点、空格、换行。
3. **字符 2-gram**：将文本转换为连续的2字符片段，统计词频。
4. **余弦相似度**：计算两个文本向量的余弦相似度，乘以100转为百分制，保留两位小数。
